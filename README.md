# Цветочный мир

Адаптивный статический каталог цветов, растений и подарков. Проект использует только HTML, CSS и JavaScript; товары и фотографии лежат рядом с сайтом. База данных, аккаунты, корзина и оплата не требуются.

## Как посмотреть сайт

Откройте `index.html` в браузере. Для локального предпросмотра из папки проекта запустите:

```bash
python3 -m http.server 4173 --bind 127.0.0.1
```

Затем откройте `http://127.0.0.1:4173`. Для публикации скопируйте содержимое папки на любой статический хостинг: шаг сборки не нужен.

## Каталог

Список товаров, категории, цены, изображения и короткие описания находятся в массиве `products` в `app.js`. Поле `price` хранит цену в рублях, а `from: true` добавляет пометку «от».

Поиск, фильтры и информационная карточка работают в браузере. Окно товара прямо сообщает, что каталог не оформляет заказ. Все изображения товара сохранены локально в WebP в `assets/products`; фоновые рисунки и значок сайта — в SVG.
